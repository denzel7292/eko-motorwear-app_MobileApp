# EKO Motorwear app: Webflow API koppeling

Deze app haalt producten en blogs rechtstreeks op uit de Webflow API met `fetch`.

Zonder ingevulde API-gegevens blijft de lokale demonstratie-data zichtbaar, zodat de app altijd werkt.

## Instellen

1. Kopieer `.env.example` naar een nieuw lokaal bestand met de naam `.env`.
2. Vul daar de Webflow Site Token en Site ID in.
3. Herstart Expo met `npx expo start -c`.
4. Open de Expo GO app op je telefoon en scan de QR-Code.
